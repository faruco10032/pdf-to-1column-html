# 論文PDF → 1カラムHTML (Chrome拡張)

Chromeのタブで表示中の論文PDFを、読みやすい1カラムHTMLに変換して新しいタブで開く拡張機能。
図・表・数式は元の見た目のまま画像として保持。変換後にブラウザの翻訳機能
(右クリック →「日本語に翻訳」)で読む。

PDF.js を使って完全にブラウザ内で動作します(PDFや変換結果を外部に送信しません)。

## インストール (デベロッパーモード)

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ この `extension` フォルダを選択

配布用ZIPから入れる手順・更新手順は [`INSTALL.txt`](INSTALL.txt) を参照。

## 使い方

1. 論文PDFをChromeで開く (arXiv等のPDF直リンク、IEEE Xplore等のPDF埋め込みページ)
2. ツールバーの拡張アイコンをクリック
3. 新しいタブで変換が始まり、終わると1カラムHTMLが表示される
4. 右クリック →「日本語に翻訳」
5. 右上の「HTMLを保存」ボタンで単体HTMLとしてダウンロードも可能
   (保存したHTMLでも引用ポップアップは動作する)

### ローカルのPDFファイル (file://) を変換する場合

`chrome://extensions` → この拡張の「詳細」→「ファイルの URL へのアクセスを許可する」をON。
その後、PDFをChromeにドラッグして開き、拡張アイコンをクリック。

## 主な機能

- 2段組の論文も正しい読み順の1カラムに再構成。段落は字下げ・行末の位置から分割
- 図・表・数式(別行立て・行内とも)は元の見た目のまま画像として保持
- 参考文献を1件ずつに再構築し、本文の引用から文献へリンク
  - 番号形式: `[1]`、`[2, 5]`、範囲 `[4]-[7]` / `[4-7]` は `4, 5, 6, 7` と個別リンクに展開
  - 著者-年形式: `[Gugenheimer et al. 2016]`、`(Simeone et al., 2015)`、
    `(Ernst & Banks, 2002)`、`(A, 2011; B & C, 2016)`、地の文の `Simeone et al. (2015)`
  - 文献リストは ACM 形式 (`著者. 2017. タイトル.`) と APA 形式 (`著者 (2015). タイトル.`) の両方に対応
- 引用にマウスを乗せると書誌情報をポップアップ表示。「Google Scholar で検索」から
  その文献のタイトルで検索できる (新しいタブ)。クリックすると文献リストへジャンプ
- Chrome翻訳をかけても引用リンクの番号と飛び先がずれないよう、引用部分は翻訳対象外
  (`translate="no"`)。ポップアップの検索には翻訳前の原文を使う
- 文献・脚注の DOI / URL はクリッカブルリンク化 (行の折り返しで分断されたURLも再結合)
- ページ内に埋め込まれたPDF (IEEE Xplore の stamp.jsp など) も実URLを自動検出して変換
- 日本語論文に対応 (CMap同梱)

## パイプライン概要 (converter.js)

1. **テキスト構造化** — PDF.jsのtextContentアイテムから行・ブロックを再構築。
   回転テキスト(arXivスタンプ)分離、カラム境界での行分割(中央線をまたぐ
   ギャップは4ptでも分割)、スタイル境界(サイズ・太字・イタリック)での
   ブロック分割、見出しパターン行・"References" などのセクション語の強制独立。
   字下げ・短い行末から段落を分割。
2. **図検出** — ページをCanvasに200dpiで描画し、テキスト矩形を消去した残りの
   インクの連結成分を図領域とする(罫線のみの表も拾える)。本文・キャプション・
   見出しを飲み込む結合は禁止。近接ラベル(軸ラベル等)は領域に取り込む。
3. **数式** — 数式フォント比率でブロック/行/スパン区間の3粒度で検出し画像化。
   別行立て数式は分割ブロック(√・分子分母・添字)を1領域に統合。
4. **読み順** — 全幅要素で帯分割し、帯内で左カラム→右カラム。
5. **後処理** — ヘッダ/フッタ/ページ番号/行番号の除去、見出しレベル推定(IEEE形式対応)、
   ドロップキャップ修正、合字の欠落修復 ("Te" → "The")、段落のカラム/ページまたぎ結合。
6. **参考文献** — 文献見出し以降を連結し直して1件ずつに分割(番号形式は `[n]`、
   著者-年形式は ACM / APA の著者・年パターンで境界を判定し、著者略歴が始まったら終了)。
   本文の引用を筆頭著者の姓+年(または番号)で照合してリンク化。

## 制約

- スキャンPDF(テキスト層なし)は非対応
- 大学プロキシ等の認証付きPDFは、タブで表示できていれば概ね取得可能
  (拡張がCookie込みでfetchする)
- 密な2段組の hanging-indent 形式の著者-年文献リストでは、文献エントリの
  境界がずれることがある
