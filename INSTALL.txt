 論文PDF → 1カラムHTML (Chrome拡張) インストール手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ インストール (2分で終わります)

 1. このZIPを好きな場所に「展開」する
    ※展開したフォルダは削除しないでください (拡張の本体です)

 2. Chromeでアドレスバーに  chrome://extensions  と入力して開く

 3. 右上の「デベロッパーモード」をONにする

 4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、
    手順1で展開したフォルダ (manifest.json が入っているフォルダ) を選択

■ 使い方

 1. 論文PDFをChromeで開く (arXiv等のPDFリンクをそのまま開けばOK)
 2. ツールバーの青い「訳」アイコンをクリック
 3. 新しいタブで変換が始まり、読みやすい1カラムHTMLが表示される
 4. ページ上で右クリック →「日本語に翻訳」
 5. 右上の「HTMLを保存」ボタンでファイルとして保存も可能

■ ローカルのPDFファイルを変換したい場合

 chrome://extensions → この拡張の「詳細」→
 「ファイルの URL へのアクセスを許可する」をON。
 その後、PDFファイルをChromeのウィンドウにドラッグして開き、
 アイコンをクリックしてください。

■ 特長

 ・2段組の論文も正しい読み順の1カラムに再構成
 ・図・表・数式は元の見た目のまま画像として保持
 ・本文の引用 [1] や [Author 2016] から参考文献へジャンプできる
 ・DOI/URLはクリッカブルリンク化
 ・日本語論文にも対応
 ・変換はすべてブラウザ内で完結 (PDFが外部に送信されることはありません)

■ 注意

 ・スキャンPDF (文字データのないPDF) は変換できません
 ・Chromeを再起動しても拡張は残ります。展開したフォルダを
   移動・削除した場合は再インストールしてください
